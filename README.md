# E-Commerce Delivery Performance Analysis Dashboard

## Project Overview

This project focuses on analyzing e-commerce delivery performance to understand order delivery timelines and identify delays. Using SQL Server and Power BI, the project examines delivery data and presents key performance indicators through an interactive dashboard.

## Business Problem

E-commerce businesses need to monitor delivery performance to maintain customer satisfaction and improve operational efficiency. Delayed deliveries can affect the customer experience. This project analyzes actual delivery dates against estimated delivery dates to identify on-time and late deliveries.

## Project Objectives

- Analyze e-commerce order and delivery data.
- Evaluate actual delivery performance against estimated dates.
- Identify on-time and late deliveries.
- Calculate key delivery performance indicators.
- Develop an interactive Power BI dashboard.

## Tools & Technologies

- SQL Server
- Microsoft Power BI
- DAX
- Excel

## Dataset

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

**Source:** Kaggle

The dataset contains e-commerce information related to orders, customers, sellers, products, and delivery timelines.

Dataset source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Project Workflow

1. **Data Understanding:** Explore the available e-commerce tables and understand their relationships.
2. **Data Preparation:** Prepare and organize order and delivery information.
3. **SQL Analysis:** Use SQL queries to analyze order statuses and delivery timelines.
4. **Delivery Classification:** Compare actual delivery dates with estimated delivery dates to classify delivered orders as on-time or late.
5. **DAX Calculations:** Create measures for delivery KPIs and performance analysis.
6. **Dashboard Development:** Build an interactive Power BI dashboard with charts, KPI cards, and filters.

## Dashboard Features

- Total Orders
- Delivered Orders
- On-Time Deliveries
- Late Deliveries
- On-Time vs Late Delivery Analysis
- Delivery Performance Visualizations
- Interactive Filters
